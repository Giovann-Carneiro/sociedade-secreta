# Sociedade Secreta

Website individual sobre séries criminais, filmes e documentários de investigação. Frontend em HTML, CSS e JavaScript puro (`public/`), API em Node.js (`src/`) e banco MySQL.

## Registro de prompts e decisões

SEMPRE, ao final de cada tarefa ou resposta neste repositório, use a habilidade `registrar-prompts` para anotar em `.docs/prompts/YYYY-MM-DD.md` o que foi solicitado e o que foi decidido.

- Vale para perguntas, planejamento e tarefas que não alteram código.
- Vale sempre que uma decisão do projeto for tomada ou revisada.
- Escreva o registro assim que o trabalho solicitado for concluído, de forma breve e objetiva.
